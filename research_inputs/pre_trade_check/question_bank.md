# 下单前拷问题库 v2.0

> 来源：博主 12 篇文章 + 行为金融学经典原则 + 自身腾讯/小米分析复盘。
> 用途：填充 `template.md` 的题目池。每次有新输入（如读到博主新文章/新书）就增量补题。
> 版本说明：v2.0 相比 v1.0 新增——起点关（事实+thesis+分类）、终局关（魔鬼代言人）、卖出条件前瞻/滞后双栏、PE 退出倍数 3x3 敏感性矩阵；废弃硬性 IRR 阈值。

---

## 术语约定

### 预期年化总回报（简称"年化总回报"）
- 定义：`股价涨幅年化 + 股东回报年化`
- 是简化估算，不是严格意义的 IRR（IRR 需 DCF 折现求解）
- 与博主自述的"年化 15%"口径一致
- 不用 IRR 这个词的原因：IRR 听起来"工程式专业"，容易让人不自觉变得过度自信，反而违背反 FOMO 初衷

### 标的分类（决定用哪套 checklist 变体）
- **红利股**：成熟期、低增长、高股东回报。代表：茅台、神华、分众、福耀。重点关 PE 历史分位 + 股东回报率 + 利润稳定性
- **成长股**：商业模式相对稳定、多业务线、稳健增长。代表：腾讯、苹果、台积电、Costco。重点关业务拆分 + 利润率杠杆 + 退出 PE 敏感性
- **赌赛道股**：业务在变形、增长曲线尚未验证、SOTP 分部估值。代表：小米、特斯拉、英伟达、泡泡玛特。重点关 SOTP + 行业终局 + 创始人因子 + 魔鬼代言人

→ 不同分类适用题目不同，题目后标 [红] / [成] / [赌] / [通用]

### 语言守则（元规则，每次填表前重读）
凡是说不出"人话"的词，必须被换掉再继续：
- ❌ IRR → ✅ 年化总回报
- ❌ DCF 折现 → ✅ 未来现金流值多少钱
- ❌ EV/EBITDA → ✅ 公司值多少钱 / 一年能赚多少
- ❌ ROIC → ✅ 公司每投入 1 块钱每年能赚回多少
- ❌ "护城河" → ✅ 具体哪种壁垒（品牌心智 / 网络效应 / 工艺 / 渠道 / 系统级…）
- ❌ "高质量公司" → ✅ 具体哪个指标（毛利率 ≥ X / ROE ≥ Y / 现金流／净利润 ≥ Z）

**原理**：术语会制造"分析很专业"的错觉，让你在错误时不敢质疑。说人话能让自我检查不被自我催眠。

## 元规则：先事实，再 thesis，再框架

**所有 checklist 必须按顺序走，不能跳**：

1. 表 0 事实清单——先把客观数据搞对
2. 表 0 thesis 一句话——先有定性判断，再算数字
3. 表 1-3 框架题——用框架校验 thesis
4. 表 4 魔鬼代言人——强制反方挑战

**违反此顺序的后果**（来自我自己的腾讯/小米复盘）：
- 先框架后数据 → 数据被用来验证已有假设，不是发现真相
- 先数字后 thesis → 没立场就硬算，得到"伪客观"的拍脑袋数字
- 跳过魔鬼代言人 → confirmation bias 一定发作

```
表 0 任一项空缺 / thesis 是红灯句式 → 拒绝
表 1 任一题目"否决条件"触发        → 拒绝
表 2 命中 ≥ 4 项                     → 拒绝
表 2 命中 ≥ 2 项                     → 强制冷静期 7 天
表 3 年化总回报矩阵中位数 < 8%       → 拒绝
表 3 矩阵全部 < 10%                  → 拒绝
```
